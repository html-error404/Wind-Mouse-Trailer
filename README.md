# WIND - Mouse Trailer

A lightweight, interactive cursor trail effect. Move your mouse to see particles follow.

**Made with:** HTML, CSS, JavaScript

---

## ⚡ Quick Start

1. Open `index.html` in your browser
2. Move your mouse around
3. Customize with the Trail Control panel

**No installation, dependencies, or setup needed.**

---

## 🎨 Features

- **7 Particle Shapes** - Star, Sparkle, Diamond, Heart, Ring, Circle, Moon
- **12+ Colors** - Red, Cyan, Magenta, Green, Yellow, Blue, White, and more
- **Adjustable Settings** - Scale, Opacity, Density
- **Real-time Customization** - Changes apply instantly
- **High Performance** - 60+ FPS on modern devices
- **Mobile Friendly** - Works on touch devices

## 💡 Pro Tips

1. **Combine colors with shapes** - Try different combinations to find your style
2. **Low opacity looks subtle** - Use 30-50% for background effect
3. **Scale affects visibility** - Larger scale = more prominent trails
4. **Toggle selectively** - Disable Particle Sparks for cleaner look

## ⚙️ Troubleshooting

| Problem | Solution |
|---------|----------|
| No trail visible | Check if "Wind Trail" is enabled and opacity > 0% |
| Low FPS | Reduce scale or disable Particle Sparks |
| Trail color wrong | Try a different color or reload page |
